1. EXECUTIVE SUMMARY
================================================================================

The challenge implements a simple XOR cipher where the entire plaintext is
encrypted using a single-byte key.

The provided ciphertext is:

    15180c21296b343d36690538236d6905226a2805316923052869396a2c692823056d6d6b6b27

The objective is to recover the single-byte XOR key and use it to decrypt the
ciphertext and obtain the flag.

Since a single byte is used as the key, there are only 256 possible keys,
making the cipher trivial to brute-force.

================================================================================
2. CIPHERTEXT ANALYSIS
================================================================================

The ciphertext is provided in hexadecimal format. The first step is to
convert it into raw bytes:

    cipher = bytes.fromhex(
        "15180c21296b343d36690538236d6905226a2805316923052869396a2c692823056d6d6b6b27"
    )

The challenge specifies that the plaintext was XORed with a single byte:

    C[i] = P[i] XOR K

where:

    C[i] = ciphertext byte
    P[i] = plaintext byte
    K    = single-byte XOR key

Since XOR is its own inverse:

    P[i] = C[i] XOR K

================================================================================
3. KEY RECOVERY
================================================================================

A single-byte XOR key can be brute-forced by testing all 256 possible values.

A useful observation is that the expected plaintext begins with:

    OBV{

The first ciphertext bytes are:

    15 18 0c 21

Assuming the first plaintext bytes are:

    4f 42 56 7b

the XOR key can be recovered as:

    0x15 XOR 0x4f = 0x5a
    0x18 XOR 0x42 = 0x5a
    0x0c XOR 0x56 = 0x5a
    0x21 XOR 0x7b = 0x5a

Therefore, the recovered key is:

    0x5A

This confirms the same key across multiple known plaintext bytes.

================================================================================
4. DECRYPTION
================================================================================

Using the recovered key:

    KEY = 0x5A

each ciphertext byte is XORed with `0x5A`:

    plaintext[i] = ciphertext[i] XOR 0x5A

The complete decryption can be performed using:

    cipher = bytes.fromhex(
        "15180c21296b343d36690538236d6905226a2805316923052869396a2c692823056d6d6b6b27"
    )

    key = 0x5A

    plaintext = bytes(b ^ key for b in cipher)

    print(plaintext.decode())

The output is:

    OBV{s1ngl3_by73_x0r_k3y_r3c0v3ry_7711}

================================================================================
6. LESSONS LEARNED
================================================================================

- Single-byte XOR provides extremely weak encryption.
- A one-byte key has only 256 possible values and can be brute-forced easily.
- Known plaintext, such as a predictable flag prefix, can immediately reveal
  the XOR key.
- XOR encryption should not be used as a standalone cryptographic mechanism
  for protecting sensitive information.
- Modern authenticated encryption algorithms should be used instead of custom
  XOR-based encryption.
